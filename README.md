# megabot

Трендовый бот для криптовалют: загрузка истории с биржи, стратегия
«следование за трендом» с размером позиции по волатильности, честный бэктест
с комиссиями и отчёт с доходностью, просадкой и коэффициентом Шарпа.

Пока это исследовательская часть: бот считает, **что** он держал бы, но сам
не торгует. Реальные ордера стоит подключать только после бэктеста и
нескольких недель торговли на бумаге (paper trading).

## Стратегия

1. **Сигнал.** Для окон 20, 50, 100 и 200 дней проверяем, выше ли цена своей
   скользящей средней. Сигнал — доля окон «за»: 0, 0.25, 0.5, 0.75 или 1.
   Усреднение по окнам нужно, чтобы результат не зависел от одного удачно
   подобранного параметра.
2. **Размер позиции по волатильности.** Целевая волатильность портфеля
   (по умолчанию 40% годовых) делится поровну между монетами. Чем бурнее
   монета, тем меньше позиция: каждая монета вносит примерно одинаковый риск.
3. **Ограничения.** Не больше 50% капитала в одной монете и не больше 100%
   суммарно (без плеча). Остальное — в кэше (USDT).
4. **Ребалансировка** раз в день на закрытии. Изменения веса меньше 2%
   капитала пропускаются, чтобы не платить комиссии за шум.

## Установка

Нужен Python 3.10+.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

```bash
# Проверка без интернета, на синтетических данных (цифры ничего не значат)
python -m megabot backtest --demo

# Скачать дневные свечи с Binance в папку data/
python -m megabot fetch

# Бэктест на реальных данных + сравнение с «купить и держать BTC»
python -m megabot backtest

# Проверка устойчивости: как стратегия работает с разными окнами
python -m megabot sweep
```

Свечи Binance скачиваются через `data-api.binance.vision` — официальный адрес
Binance только для рыночных данных. Он работает и там, где основной
`api.binance.com` заблокирован. Можно взять и другую биржу: `--exchange okx`,
`--exchange bybit`, `--exchange kraken` (у Kraken пары вида `BTC/USD`).
Данные кэшируются в `data/`; `--refresh` скачивает заново.

Отчёт сохраняется в `reports/`: `equity.png` (график капитала и просадки)
и `equity.csv` (те же данные по дням).

### Основные параметры

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `--symbols` | BTC ETH BNB XRP ADA LTC (к USDT) | Монеты. Первая используется как бенчмарк |
| `--since` | 2017-01-01 | Начало истории |
| `--lookbacks` | 20,50,100,200 | Окна скользящих средних |
| `--target-vol` | 0.40 | Целевая годовая волатильность портфеля |
| `--max-weight` | 0.5 | Максимум капитала в одной монете |
| `--max-gross` | 1.0 | Максимальная суммарная позиция (1.0 = без плеча) |
| `--allow-short` | выкл. | Шорты в нисходящем тренде (нужны фьючерсы) |
| `--fee` | 0.001 | Комиссия за сделку (0.1%, тейкер на споте Binance) |
| `--slippage` | 0.0005 | Проскальзывание (0.05%) |
| `--threshold` | 0.02 | Минимальное изменение веса для сделки |

Полный список: `python -m megabot backtest --help`.

## Как читать отчёт

- **CAGR** — среднегодовая доходность с учётом сложного процента.
- **Максимальная просадка** — самое большое падение капитала от пика. Это
  главный показатель того, выдержите ли вы стратегию психологически.
- **Коэффициент Шарпа** — доходность на единицу риска. Для одной стратегии
  после издержек 0.5–1.0 уже хорошо; значение выше 2 на истории — повод
  искать ошибку.
- **Calmar** — CAGR, делённый на максимальную просадку.
- **Оборот в год** — сколько раз за год через сделки проходит капитал.
  Вместе с «издержками в год» показывает, сколько съедают комиссии.
- **Доходность по годам** — у трендовых стратегий нормальны убыточные годы
  в боковом рынке. Смотрите, не держится ли весь результат на одном годе.

Трендовая стратегия почти никогда не обгоняет «купить и держать» в сильный
бычий рынок. Её задача другая: меньшая просадка при сопоставимой доходности,
то есть более высокий Шарп и Calmar.

## Результаты на истории

Снимок на 28.09.2026: Binance, дневные свечи, 6 монет по умолчанию, издержки
0.15% за сделку. Период 04.03.2018 — 28.09.2026 (до марта 2018 шёл прогрев
сигнала).

| | Тренд | Держать BTC |
|---|---|---|
| Среднегодовая доходность | 24.2% | 26.0% |
| Волатильность | 21.3% | 62.3% |
| Коэффициент Шарпа | 1.12 | 0.69 |
| Максимальная просадка | -28.8% | -76.6% |
| Худший месяц | -8.3% | -40.0% |
| Средняя загрузка капитала | 28% | 100% |

Доходность почти как у BTC при просадке в 2.7 раза меньше.

Проверки устойчивости:

| Вариант | CAGR | Шарп | Макс. просадка |
|---|---|---|---|
| Базовый | 24.2% | 1.12 | -28.8% |
| Комиссии ×2 (0.3% за сделку) | 21.8% | 1.03 | -31.7% |
| Комиссии ×4 (0.6% за сделку) | 17.2% | 0.85 | -37.2% |
| Только BTC + ETH (меньше ошибки выжившего) | 30.5% | 1.17 | -33.6% |
| С шортами (фандинг не учтён) | 20.7% | 0.85 | -44.3% |
| Целевая волатильность 20% | 12.5% | 1.13 | -14.5% |
| Целевая волатильность 60% | 33.0% | 1.07 | -41.2% |
| Первая половина: 03.2018 — 06.2022 | 31.9% | 1.39 | -19.8% |
| Вторая половина: 07.2022 — 09.2026 | 16.7% | 0.84 | -21.7% |

- Любое окно от 10 до 300 дней даёт Шарп 0.9–1.25 (`sweep`), так что
  результат не держится на одном подобранном параметре.
- Шорты ухудшают результат. Лучше оставить только long.
- Во второй половине периода стратегия заметно слабее (Шарп 0.84 против
  1.39) и отстала от BTC (CAGR 16.7% против 41.1%). Преимущество трендовых
  стратегий на крипте со временем уменьшается.

Это прошлое, а не обещание: будущая доходность может быть ниже.

## Что учтено, чтобы бэктест был честным

- **Нет подглядывания в будущее.** Вес, рассчитанный по закрытию дня t,
  влияет только на доходность дня t+1. Это проверяется тестами.
- **Незакрытая свеча отбрасывается** при загрузке.
- **Комиссии и проскальзывание** списываются с каждой сделки.
- **Веса дрейфуют** вместе с ценами между ребалансировками, как в реальном
  портфеле.
- **Прогрев.** Бэктест и бенчмарк начинаются с одной даты, когда у стратегии
  уже хватает истории для сигнала.
- **Проверка устойчивости** (`sweep`) сравнивает окна на одном и том же периоде.

## Ограничения

- **Ошибка выжившего.** Монеты по умолчанию выбраны сегодня, зная, что они
  дожили до сегодняшнего дня. Реальный бот в 2018 году мог выбрать монеты,
  которые потом умерли. Это завышает результат.
- Сделки считаются по цене закрытия дня. В реальности цена исполнения будет
  немного другой; это частично покрывает `--slippage`.
- Для шортов не учитываются фандинг и стоимость заёмных средств.
- Не учтён риск самой биржи (взлом, банкротство, блокировка вывода).
- Прошлые результаты не гарантируют будущих.

## Структура

```
megabot/
  data.py      загрузка свечей через ccxt, кэш в CSV, синтетические данные
  strategy.py  сигнал тренда и размер позиции по волатильности
  backtest.py  симуляция портфеля с издержками и дрейфом весов
  metrics.py   CAGR, Шарп, Сортино, просадка и другие метрики
  report.py    текстовый отчёт, CSV и график
  cli.py       команды fetch, backtest, sweep
tests/         тесты (pytest)
```
